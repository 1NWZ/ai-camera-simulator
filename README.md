# AI 相机模拟效果 · ai-camera-simulator

将用户照片制作成理光负片、富士胶片、柯达色彩或奥林巴斯 CCD 风格，输出上下分屏相机展示图和独立效果照片。

## 完整 Skill 包

下载 [ai-camera-simulator.zip](ai-camera-simulator.zip)，解压后使用其中的 `ai-camera-simulator/` 文件夹。完整包包含 `SKILL.md`、`scripts/`、`references/` 与 `assets/`，保留全部相对路径。

本仓库以完整压缩包交付；请解压后使用，不要把 ZIP 本身当作 Skill 文件夹。

## 当前规则

- 有氛围描述时直接选择合适效果，不要求用户先选品牌菜单。
- 对话简短自然、亲切；换色调直接处理，不重复确认。
- 包含最新 CCD、理光与柯达色彩规则、参考图库和相机素材。
- 默认 3:4 上下等分拼图，上屏展示原图，下屏展示效果照。

## 使用示例

上传照片并说：“帮我用这个 Skill 修一下图片色调，我想要日系胶片一些的滤镜。”

也可直接指定：“理光负片”“富士胶片”“柯达色彩”或“奥林巴斯 CCD”。

图像制作需要可用的 AI 图像编辑工具；代码后期依赖 Python 3、Pillow 和 NumPy，详见解压后的 `SKILL.md` 与 `scripts/requirements.txt`。

参考照片按用户提供的风格素材保留，品牌名称用于创作方向，不代表官方色彩标定。未额外授予第三方图片的再分发许可。
